GitHub에 저장소가 안 보이거나 권한 화면이 나와요.

Vercel의 GitHub 연결 화면에서 현재 로그인한 계정을 확인하세요. 저장소 접근을 묻는다면 이번 실습 저장소에 필요한 권한을 허용하세요.

4단계에서 ‘다른 이름 만들기’를 누르고, 새 이름을 복사해 다시 입력하세요.

환경 변수나 결제 정보를 입력하라고 나와요.

이 눈 구조 앱은 API 키나 외부 데이터베이스를 사용하지 않아요. 다른 템플릿을 선택하지 않았는지 강사와 확인하세요.

배포가 Error로 끝났어요.

오류가 난 배포의 Build Logs를 열고 오류 문구를 강사에게 보여 주세요. 4단계의 Vite / npm run build / dist 설정과 비교해요.

눈 모형이 안 보여요.

잠시 기다렸다가 새로고침하세요. Chrome 또는 Edge의 최신 버전과 3D 그래픽(WebGL) 사용 가능 여부를 확인하세요. 학교 네트워크가 vercel.app 접속을 차단하는지도 확인해요.

앱 주소를 저장했는데 실행이 안 돼요.

이 안내서는 주소 형식을 확인해요. 서버의 배포 성공까지 자동으로 확인하지는 않아요. Vercel에서 Ready인지 확인하고 Visit로 연 주소를 다시 복사해 주세요.

완료 기록이 사라졌어요.

강사용 설정

눈 구조 앱 원본 주소가 설정되어 있어요. 다른 저장소를 쓸 경우에도 API 키 없이 배포 가능한지 먼저 확인해 주세요.

https://github.com/소유자/저장소 형태로 입력해요. 이 안내의 설정표는 현재 눈 구조 앱 기준이에요.

연수생에게 전달할 때

‘설정 담아 HTML 내려받기’로 받은 HTML 파일 하나만 나누어 주세요. 파일을 더블클릭하면 안내가 열리고, 가입과 배포에는 인터넷이 필요해요. 비밀번호와 토큰은 이 파일에 입력하지 않아요.

앱·GitHub 저장소·Vercel 배포에는 영향을 주지 않아요.
